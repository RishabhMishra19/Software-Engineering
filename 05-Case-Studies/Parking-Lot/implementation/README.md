# Parking Lot implementation

This directory contains the runnable reference implementation for the Parking Lot case study.

## What This Implementation Demonstrates

The reference model demonstrates spot compatibility, ticket/payment states, exact fees, release, and concurrent allocation. It is a small executable teaching
model, not a production service. Start with the [compile and run guide](java/README.md),
which introduces the source file and explains how its self-checks are executed.
