# BookMyShow implementation

This directory contains the runnable reference implementation for the BookMyShow case study.

## What This Implementation Demonstrates

The reference model demonstrates seat holds, booking/payment transitions, duplicate callbacks, expiry, and concurrent claims. It is a small executable teaching
model, not a production service. Start with the [compile and run guide](java/README.md),
which introduces the source file and explains how its self-checks are executed.
