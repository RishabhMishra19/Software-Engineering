# Splitwise implementation

This directory contains the runnable reference implementation for the Splitwise case study.

## What This Implementation Demonstrates

The reference model demonstrates exact money, split allocation, idempotent expenses, zero-sum balances, and settlements. It is a small executable teaching
model, not a production service. Start with the [compile and run guide](java/README.md),
which introduces the source file and explains how its self-checks are executed.
