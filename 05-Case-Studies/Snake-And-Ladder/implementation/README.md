# Snake and Ladder implementation

This directory contains the runnable reference implementation for the Snake and Ladder case study.

## What This Implementation Demonstrates

The reference model demonstrates board validation, deterministic dice, overshoot, transition chains, turns, and winning. It is a small executable teaching
model, not a production service. Start with the [compile and run guide](java/README.md),
which introduces the source file and explains how its self-checks are executed.
